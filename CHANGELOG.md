# Changelogs

## 1.3.1

- Fixed a crash caused when shearing sheep dyed with dyes from the Dye Depot mod.
- Sheep dyed with unknown or unsupported dyes will now drop white wool by default instead of causing a game crash when sheared.

## 1.3.0

- Fixed a bug where shearing a sheep did not reset `thickness`.
- Added a new advancement under Vanilla → Husbandry, which is awarded when shearing a sheep with shears.

## 1.2.0

- Fixed server-side crashes

## 1.1.0

- Sheep now spawn with a random thickness from 1 to 10, with decreasing weight as thickness increases.
- Fixed a bug where baby sheep could be sheared in the Forge version.

## 1.0.0

- Initial release
